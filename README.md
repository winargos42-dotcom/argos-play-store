# ARGOS — Public Play Store assets

This repository hosts the public-facing assets required by Google Play Console for the
**ARGOS** Android companion app (developer account `winargos42` / ID `5230640315904187851`).

## Contents

| File | Purpose |
|---|---|
| `index.html` | GitHub Pages root — served as the public Privacy Policy URL |
| `styles.css` | Stylesheet for the Privacy Policy page |
| `PRIVACY_POLICY.md` | Markdown source of the privacy policy (mirror of HTML) |
| `STORE_LISTING.md` | App title, short & long description, tags, contact |
| `CONTENT_RATING.md` | Data Safety, IARC questionnaire, declarations |

## Live Privacy Policy URL

Once GitHub Pages is enabled on the `main` branch (root), the policy will be served at:

    https://winargos42-dotcom.github.io/argos-play-store/

Paste that URL into Google Play Console → *App content → Privacy policy*.
